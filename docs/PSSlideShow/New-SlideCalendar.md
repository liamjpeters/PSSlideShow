# New-SlideCalendar

## SYNOPSIS

Adds a month calendar to a slide.

## SYNTAX

### __AllParameterSets

```
New-SlideCalendar [-Year <int>] [-Month <int>] [-Event <Object[]>] [-HighlightColor <string>]
 [-HideHeader] [-Border <SlideBorder>] [-Culture <string>] [-HPadding <int>] [-VPadding <int>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Adds a month calendar to a slide. Highlight specific days with **Event**, which accepts `DateTime`
values, day numbers (interpreted against **Year**/**Month**), or hashtables with a `Date` key (and an
optional `Color`).

## EXAMPLES

### Example 1: A month with highlighted days

```powershell
New-SlideCalendar -Year 2026 -Month 8 -Event 3, 14, 25 -HighlightColor cyan
```

Renders August 2026 with the 3rd, 14th, and 25th highlighted in cyan.
