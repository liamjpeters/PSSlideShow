# PSSlideShow Module

## Description

Author and present interactive terminal slide shows using a PowerShell DSL.

## PSSlideShow Cmdlets

### [New-Slide](New-Slide.md)

Creates a single slide from a content script block.

### [New-SlideAlert](New-SlideAlert.md)

Adds a GitHub-style alert callout to a slide.

### [New-SlideBarChart](New-SlideBarChart.md)

Adds a horizontal bar chart to a slide.

### [New-SlideBreakdownChart](New-SlideBreakdownChart.md)

Adds a proportional breakdown chart to a slide.

### [New-SlideCalendar](New-SlideCalendar.md)

Adds a month calendar to a slide.

### [New-SlideCanvas](New-SlideCanvas.md)

Adds a pixel canvas to a slide.

### [New-SlideCode](New-SlideCode.md)

Adds a syntax-highlighted code block to a slide.

### [New-SlideColumn](New-SlideColumn.md)

Defines a column region inside New-SlideColumns.

### [New-SlideColumns](New-SlideColumns.md)

Arranges regions side-by-side.

### [New-SlideDynamic](New-SlideDynamic.md)

Adds a periodically updated view to a slide.

### [New-SlideFiglet](New-SlideFiglet.md)

Adds large FIGlet banner text to a slide.

### [New-SlideList](New-SlideList.md)

Adds a bulleted or numbered list to a slide.

### [New-SlideQrCode](New-SlideQrCode.md)

Adds a complete QR code to a slide.

### [New-SlideRow](New-SlideRow.md)

Defines a row region inside New-SlideRows.

### [New-SlideRows](New-SlideRows.md)

Arranges regions stacked vertically.

### [New-SlideTable](New-SlideTable.md)

Adds a table to a slide.

### [New-SlideText](New-SlideText.md)

Adds a paragraph of text to a slide.

### [New-SlideTree](New-SlideTree.md)

Adds a hierarchical tree to a slide.

### [New-SlideTreeNode](New-SlideTreeNode.md)

Adds a node to the enclosing tree.

### [Start-SlideShow](Start-SlideShow.md)

Launches the interactive slide show.
